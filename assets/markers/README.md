# Наборы знаков пищи и поста

Встроенные наборы содержат восемь печатаемых знаков в одном и том же порядке:

1. `fast-no-fish.png` — постный день без рыбы;
2. `fish.png` — разрешается рыба;
3. `boiled-with-oil.png` — разрешается варёная пища с маслом (елеем);
4. `boiled-no-oil.png` — разрешается варёная пища без масла (елея);
5. `dry-eating.png` — сухоядение;
6. `strict-fast.png` — строгий пост, ничего нельзя;
7. `dairy-eggs.png` — разрешаются молочные продукты и яйца;
8. `memorial.png` — день особого поминовения усопших.

Знак `no-fast.png` не показывается в календаре и не входит в импортированные
наборы: обычный день по требованию макета остаётся без картинки.

Четырнадцать листов пользователя разделены на 112 самостоятельных PNG 512×512
с сохранённой прозрачностью. Для листа `minimal-dark`, содержащего десять
вариантов, две повторные альтернативы пропущены, а восемь файлов сопоставлены со
списком выше. Импорт воспроизводится командой:

```powershell
npm run assets:food-markers -- "ПАПКА_С_ЛИСТАМИ" "public/assets/markers"
```

Импорт проверяет размеры исходных листов, полный состав каждого набора и точные
дубликаты среди новых и ранее установленных изображений.
