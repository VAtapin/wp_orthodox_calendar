# Historical changelog

= 1.3.62 =
* Corrected the Plugin URI for WordPress.org submission; it now differs from the author URL.

= 1.3.61 =
* The icon limit applies only to displayed cards; the gallery retains every icon and image for the day.
* Icon clicks are captured before theme lightboxes so the single plugin gallery opens consistently.
* Added Russian and German translations for the plugin name and description shown in WordPress.

= 1.3.60 =
* Prepared the first WordPress.org release, including deployment metadata and the GitHub Actions SVN workflow.
* Added the complete icon gallery: one dialog keeps image previews for the selected icon at the top and all daily icons in a light bottom strip.

= 1.3.52 =
* Нажатие на икону дня открывает общую галерею всех образов и всех их изображений; карточки и изображения подгружаются по мере просмотра.

= 1.3.51 =
* Миниатюры икон дня уменьшены до 70 пикселей по ширине и высоте.

= 1.3.50 =
* Каталог икон дня теперь сохраняет все изображения каждого образа, соблюдает лимит образов и открывает описание первой карточкой модального просмотра с навигацией по выбранному образу.

= 1.3.49 =
* Если язык текста не задан, библиотеки молитв, тропарей, кондаков и других богослужебных текстов открывают редакцию с наибольшим числом материалов.

= 1.3.48 =
* `cu` и `cu-civil` снова используют Monomakh Unicode; сохранён раздельный выбор языковых редакций.
* Во всех книгах библиотеки доступен ползунок размера текста; текст использует всю доступную ширину большого окна.
* Шрифты теперь регистрируются через CSS @font-face вместо JavaScript FontFace, чтобы браузер не переходил молча на системный fallback.
* При переходе чтения на следующую главу выводится заголовок главы.
* Окна тропарей, кондаков, молитв, величаний, Часослова, акафистов и канонов открываются во весь размер окна чтений.

= 1.3.43 =
* Перед каждым стихом чтения выводится только номер стиха; код книги и главы не повторяются.

= 1.3.42 =
* Панель перевода и размера текста чтений выводится на странице только для inline-режима, а для окна — только внутри него.
* Ползунок размера чтения действует и во всплывающем окне.

= 1.3.41 =
* В конструкторе и редакторе Gutenberg высота картинки поста вводится числом в пикселях; ширина определяется исходными пропорциями.
* Убрано CSS-переопределение, которое возвращало размер изображения к 44 × 44 px.

= 1.3.40 =
* Карточка дня больше не показывает картинку поста, когда API сообщает `no-fast`.
* Все 16 наборов проверяются в предпросмотре и на публичной карточке именно на постной дате.

= 1.3.39 =
* Запоздалый ответ предпросмотра больше не подменяет выбранный набор картинок поста.
* Единый выбор Monomakh и гражданского шрифта во всех богослужебных разделах без изменения текста.
* cu и cu-civil запрашиваются отдельно; отсутствующая версия cu не подменяется гражданской.


= 1.3.38 =
Выбор шрифта церковнославянских текстов определяется редакцией: гражданская использует обычный гражданский шрифт, традиционная — Monomakh; общее правило языка применяется только к текстам без признака редакции.

= 1.3.37 =
Русские сборники разделяются на тропари и кондаки; для этих справочников показываются только доступные языки; гражданская церковнославянская редакция использует читаемый гражданский шрифт.

= 1.3.36 =
Немецкие тропари и кондаки из локальной библиотеки Bible Desktop открываются в читателе вместе с остальными немецкими изданиями.

= 1.3.35 =
Полные тексты Bible Desktop; отдельный язык текста; акафисты и каноны; фильтры по доступным данным; постраничный справочник.

= 1.3.34 =
Уставные указания перед назначенными текстами Часов; пояснение неполных назначений дня.

= 1.3.33 =
Исправлен фильтр уровней памятей: Пасха и великие праздники больше не исчезают при выборе всех уровней.

= 1.3.32 =
Если API-ключ не задан, Gutenberg явно сообщает об этом в блоке и ведёт на вкладку подключения. Ключ в редактор не передаётся.

= 1.3.28 =
Немецкие подписи карточки дня, даты, загрузки, копирования и справочников. Смена языка и раздела Часослова обновляет одно окно вместо открытия нового. Добавлены ссылки на немецкие православные тексты; встроенный церковнославянский корпус явно обозначен. Полное последование доступно по ссылке на издание.
